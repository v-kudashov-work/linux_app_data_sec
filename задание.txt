1. Модуль app_data_sec это модуль ядра системы Linux или иная подходящая для задачи технология.
2. При установке модуля app_data_sec в системе Linux появляется конфиг файл, доступный на чтение и не доступный на изменение без root. В этом файле храниться признак включения модуля и возможно другой конфиг.
3. В любой папке пользователь Linux может создать папку .app_data_sec. Модуль app_data_sec ограничивает доступ в такую папку, т.е. если в пути к файлу будет папка .app_data_sec, включаются правила ограничения доступа.
4. Внутри папки .app_data_sec каждое приложение может создать свою папку, доступ к которой оно сможет получить, но для этого нужно выполнить несколько условий:
4.1. Название папки должно состоять из пути к исполняемому файлу приложения, слеши в котором заменены на символы |7|. Например: |7|bin|7|configure-printer для /bin/configure-printer
4.2. При обращении к папке модуль app_data_sec будет просматривать список вложенности процесса и если хотя бы у одного из исполняемых файлов процесса путь совпадёт, разрешит доступ. В остальных случаях доступ блокируется.
5. Папки .app_data_sec и их содержимое может быть удалено только из root доступа.
6. Так же в системе должен присутствовать файл, недоступный на чтение кроме как из root, в котором храниться конфигурация доступа для других папок в системе. Конфигурация должна позволять записать несколько записей. Каждая запись хранит путь к папке и список путей к исполняемым файлам, у которых есть доступ к этой папке. app_data_sec при обращении к файлам сверяет путь и если он содержит одну из записей, проверяет список вложенности процесса и если хотя бы у одного из исполняемых файлов процесса путь совпадёт в записью, разрешит доступ или заблокирует доступ в ином случае.
7. Должны поддерживаться Alt Linux, Ubuntu и Debian последних версий с длительной поддержкой.
